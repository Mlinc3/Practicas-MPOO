
CONTEXTO
Desarrollar un simulador de zoológico en Java que permita administrar diferentes especies de animales mediante programación orientada a objetos.

El proyecto debe demostrar el uso de interfaces, clases abstractas, herencia, polimorfismo, colecciones dinámicas, `instanceof` y casting, siguiendo los conceptos vistos en clase.

OBJETIVO
Crear un simulador de zoológico donde diferentes animales compartan una interfaz común y puedan ser administrados dinámicamente mediante una colección `ArrayList`.

REQUERIMIENTOS

1. Crear una interfaz `Animal` que establezca los métodos comunes para todos los animales:
   - `getNombre()`
   - `getEspecie()`
   - `getEdad()`
   - `presentarse()`
   - `emitirSonido()`
   - `alimentarse()`

2. Crear una clase abstracta `AnimalBase` que implemente la interfaz `Animal`.
   - Contener los atributos privados `nombre` y `edad`.
   - Implementar los métodos generales.
   - Declarar los métodos específicos que deberán sobrescribir las clases hijas.

3. Crear las siguientes clases que hereden de `AnimalBase`:
   - `Leon`
   - `Elefante`
   - `Jirafa`
   - `Mono`
   - `Aguila`
   - `Delfin`
   - `Tortuga`
   - `Serpiente`

4. Crear una interfaz adicional llamada `Entrenable`.
   - Contener el método `entrenar()`.
   - Implementarla únicamente en los animales que puedan realizar actividades de entrenamiento, como `Mono` y `Delfin`.

5. Crear una clase `Main` que administre el zoológico mediante un `ArrayList<Animal>`.

FUNCIONALIDADES DEL SIMULADOR

El programa deberá contar con un menú que permita:

1. Mostrar todos los animales registrados.
2. Mostrar los sonidos de los animales.
3. Alimentar a todos los animales.
4. Registrar nuevos animales.
5. Entrenar a los animales que implementen `Entrenable`.
6. Buscar un animal por nombre.
7. Eliminar un animal.
8. Salir del programa.

APLICACIÓN DEL POLIMORFISMO

Utilizar recorridos `for-each` para ejecutar los métodos de los animales mediante referencias de tipo `Animal`.

También implementar `instanceof` y casting para identificar qué animales implementan la interfaz `Entrenable`.

Ejemplo de la lógica esperada:

```java
for (Animal animal : zoologico) {
    animal.presentarse();
}

for (Animal animal : zoologico) {
    animal.emitirSonido();
}

for (Animal animal : zoologico) {
    if (animal instanceof Entrenable) {
        ((Entrenable) animal).entrenar();
    }
}
```

- Separar las responsabilidades de cada clase.
- No colocar toda la lógica dentro de `Main`.
- Utilizar nombres de clases y métodos en español.

- Evitar código innecesariamente complejo.

- Utilizar `@Override` al sobrescribir métodos.
