RETO: SISTEMA DE GESTION DE ESTUDIANTES (ENCAPSULAMIENTO Y VALIDACION DE REGLAS DE NEGOCIO)

CONTEXTO:
Se utiliza Java 21 en la ide intellijeid, sin paquetes adicionales. Es una practica de MPOO, Facultad de Ingenieria UNAM. El reto es crear un sistema de gestion de estudiantes donde toda modificacion de los datos pase por metodos publicos que validen reglas de negocio (edad, promedio, creditos, etc.). Todo se ejecuta en consola, sin package.

OBJETIVO:
Que la clase Estudiante proteja su estado interno: los atributos son private y la unica forma de leerlos o cambiarlos es mediante getters y setters publicos. Cada setter valida la regla de negocio de su atributo antes de asignar; si el valor no cumple, no se modifica el atributo y se imprime un mensaje de error.
Estudiante tiene 4 atributos: nombre (String), edad (int), promedio (double) y creditos (int).
Tiene un constructor (nombre, edad, promedio, creditos) que NO asigna directo: llama a los 4 setters para que los valores iniciales tambien pasen por las validaciones.
Reglas de negocio:
- nombre: no puede ser null ni estar vacio ni tener solo espacios. Mensaje: "Error: el nombre no puede estar vacío."
- edad: entre 15 y 99 inclusive. Mensaje: "Error: la edad debe estar entre 15 y 99."
- promedio: entre 0 y 10 inclusive. Mensaje: "Error: el promedio debe estar entre 0 y 10."
- creditos: entre 0 y 400 inclusive. Mensaje: "Error: los créditos deben estar entre 0 y 400."
Si un valor es invalido, el atributo conserva su valor anterior (en el constructor, como no hay valor anterior, queda en el valor por defecto de Java: null, 0, 0.0 y 0).
toString() devuelve los 4 datos, uno por linea.
Son 2 archivos: Estudiante y Main.

public class Main {
    public static void main(String[] args) {
        Estudiante estudiante = new Estudiante("Carlos", 19, 8.5, 120);

        System.out.println("ESTUDIANTE INICIAL");
        System.out.println(estudiante);

        estudiante.setNombre("Mario");
        estudiante.setEdad(20);
        estudiante.setPromedio(9.2);
        estudiante.setCreditos(150);

        System.out.println("\nESTUDIANTE ACTUALIZADO");
        System.out.println(estudiante);

        estudiante.setNombre("");
        estudiante.setEdad(10);
        estudiante.setPromedio(11);
        estudiante.setCreditos(-30);

        System.out.println("\nRESULTADO FINAL");
        System.out.println(estudiante);
    }
}

RESTRICCIONES
No se puede modificar el Main.
Los 4 atributos son private; ningun archivo puede acceder a ellos directamente, solo con getters y setters.
Toda asignacion a un atributo debe pasar por su setter, incluida la del constructor (el constructor llama a los setters, no usa this.atributo = valor por su cuenta).
Cada setter tiene la validacion con if-else y en el else imprime su mensaje de error; no se usan excepciones ni return con valores.
Los rangos son inclusivos: 15 y 99 son edades validas, 0 y 10 son promedios validos, 0 y 400 son creditos validos.
Se debe usar @Override en toString.
Sin Scanner ni datos que pida el usuario, el Main ya trae todos los datos.
